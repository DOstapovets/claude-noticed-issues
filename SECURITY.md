# Security policy

Please do not report security problems in public issues or discussions.

Report them privately through
[GitHub's private vulnerability reporting](https://github.com/DOstapovets/claude-noticed-issues/security/advisories/new)
(the **Security** tab, then **Report a vulnerability**). You will get an answer there,
and a fix is released before the details are made public.

Only the latest version on `main` receives fixes.
